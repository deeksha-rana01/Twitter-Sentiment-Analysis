# Twitter-Sentiment-Analysis
Sentiment analysis of tweets using Python and TextBlob to classify opinions as Positive, Negative, or Neutral through NLP, data preprocessing, and visualization.

### Project Overview
This project analyzes tweets using Natural Language Processing (NLP) and classifies their sentiment into Positive, Negative, or Neutral categories using TextBlob.

### Objectives
- Perform tweet text preprocessing.
- Calculate sentiment polarity using TextBlob.
- Classify tweets into three sentiment categories.
- Visualize sentiment distribution.
- Evaluate sentiment predictions.

### Technologies Used
- Python
- Pandas and NumPy
- TextBlob
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

### Methodology
- Data loading and exploration
- Data cleaning and preprocessing
- Sentiment polarity calculation
- Sentiment classification
- Data visualization
- Performance evaluation using accuracy, precision, recall, F1-score, and confusion matrix

### Conclusion
This project demonstrates how Natural Language Processing can be used to analyze tweet sentiment through text preprocessing, polarity calculation, classification, and visualization.
